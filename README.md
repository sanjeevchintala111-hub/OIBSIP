# Exploratory Data Analysis on Retail Sales Data

## 1. Project Overview
This project is part of the **Oasis Infobyte Data Analytics Internship — Task 1**.

The objective is to perform Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, understand customer behavior, and generate actionable business insights.

## 2. Objectives
- Inspect the dataset and identify missing values and duplicates.
- Calculate descriptive statistics for numerical columns.
- Analyze monthly and quarterly sales trends.
- Explore customer age groups and gender distribution.
- Identify top-selling product categories and compare their revenue.
- Examine correlations between numerical variables.
- Develop actionable business recommendations based on the findings.
